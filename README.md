# Wonder Maker

**Wonder Maker** is an ongoing fan-made Mario Maker project currently being rebuilt from the ground up.

The current version, **Alpha v0.0.1**, is still in development, and there is **no public release of the game using the new codebase yet**.

## Features

* Mario Maker-inspired level creation
* New game architecture being developed from scratch
* Powered by a custom high-level engine called **Wonder Studio**
* Designed for the new Wonder Maker development workflow

## Development

The project is being developed using **Godot 4.7 Beta** in combination with **Wonder Studio**, a high-level engine created specifically for Wonder Maker.

The **Wonder Maker and Wonder Studio Godot source code is closed to the public**.

This repository contains the **public Wonder Maker project**, which is intended to be opened and edited through **Wonder Studio**.

## Status

**Alpha v0.0.1 is currently in development.**

There is currently no public build of the game using the new codebase. The first public release, **Alpha v0.0.1**, is expected to launch sometime in **2026**.
